# Prompt engineering, explained simply

Learn to give AI models clear instructions, supply useful context, and check whether the results are good enough for the task. Start with everyday examples, then move into evaluation, retrieval, tool use, and production workflows.

This guide uses plain language and practical exercises. It was created with AI assistance and should not be described as entirely human-written. Examples are learning materials, not claims of measured model performance.

## Start here

1. Follow the [learning path](LEARNING-PATH.md).
2. Read a lesson, try its prompt, and check the output yourself.
3. Save failures in the [evaluation worksheet](templates/evaluation.md).
4. Build the [capstone](projects/support-assistant.md).

No programming is needed for the first lessons. API, tool, and production sections assume basic application knowledge. You can practice in a chat interface without an API key; API use may incur provider charges.
