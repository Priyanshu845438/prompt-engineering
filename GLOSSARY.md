# Glossary

| Term | Meaning |
| --- | --- |
| Prompt | Instructions and context supplied to a model |
| Token | A unit used to represent input or output |
| Context window | The amount of information a model can handle in a request |
| Hallucination | A plausible output that is false or unsupported |
| Zero-shot | A task request without demonstration examples |
| Few-shot | A request that includes demonstration examples |
| Grounding | Connecting claims to supplied or retrieved evidence |
| RAG | Retrieval-augmented generation: retrieve information, then generate using it |
| Tool call | A structured request for an application to execute an operation |
| Agent | A workflow that chooses and repeats actions toward a goal |
| Prompt injection | Untrusted content attempting to redirect the workflow |
| Evaluation | Checking outputs against defined expectations |
| Fine-tuning | Additional model training using examples |
| Context engineering | Designing the information and state made available to a model |
| Abstention | Declining to assert an answer when evidence is insufficient |
