# Learning path

[Home](README.md)

| Stage | Lessons | What to demonstrate |
| --- | --- | --- |
| First prompts | 1–4 | A clear task, representative examples, and checked output |
| Reliable results | 5–8 | A baseline, evaluation cases, and evidence-backed answers |
| Application workflows | 9–12 | Tool boundaries, injection tests, and runnable checks |
| Independent practice | 13–15 | A useful workflow with measured tradeoffs |

Take one lesson per session or combine familiar topics. There is no fixed completion time or job guarantee. Revisit a lesson when an actual failure makes it relevant.

For each session record: what you wanted, the original prompt, actual output, what failed, one change, and the result. Keep model and date with each record.

Complete the capstone after the grounding and security lessons. Review it again after the production lesson.
