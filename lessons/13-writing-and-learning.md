# Use prompts for clear writing and active learning

[Home](../README.md) · [Learning path](../LEARNING-PATH.md)

## The idea

Give the audience, purpose, facts, and tone. For learning, request a short explanation, a worked example, and a question you answer yourself. Good editing preserves meaning; good tutoring exposes misunderstanding.

## Try this prompt

```text
Teach CSS specificity to someone who knows basic HTML. Use one small example, then ask me to predict which rule wins. Wait for my answer before explaining it.
```

This is a practice prompt, not a recorded model response. Replace bracketed placeholders before using it.

## Practice and check

Answer the question without help. Then ask for feedback tied to your actual mistake.

Save the input, prompt version, model, output, and your checks. Explain one failure in your own words before revising the prompt.

## Common mistake

Do not publish invented personal experiences or claim AI-assisted text was entirely human-authored.
