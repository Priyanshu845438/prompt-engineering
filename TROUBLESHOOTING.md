# Troubleshooting

| Symptom | Likely next step |
| --- | --- |
| Vague answer | Define audience, task, and success criteria |
| Invented details | Supply evidence and test missing-information behavior |
| Wrong format | Give a schema; validate in code where available |
| Ignores a requirement | Remove conflicts and add a targeted evaluation case |
| Poor citations | Inspect retrieval and check claim-to-passage support |
| Overly long response | Set a useful length and prioritize required content |
| Inconsistent labels | Clarify label definitions and add boundary examples |
| Tool claims success without proof | Require actual tool results; enforce this in code |
| Rising cost or latency | Measure calls and tokens; simplify only after quality checks |
| Fails after a model change | Rerun the evaluation set and compare recorded versions |

Change one likely cause at a time. If the needed data or capability is absent, a more elaborate prompt may not solve the problem.
